# Sprint Goals
## Sprint goal 4: JavaScript
Vårt fokus är att bygga ett fungerande bokningsformulär som tar emot värden och skriver ut en bekräftelse på bokning.
Vi ska skapa en detaljvy i form av en pop-up med information om evenemangen, man ska också komma åt bokningsformuläret därifrån.

Det krävs för att besökare ska kunna se information om evenemanget och anmäla sig till valt evenemang.

Detta bekräftas när vi testar formuläret med testdata och rätt information skrivs ut som en bekräftelse.

1 vecka

## Sprint goal 3: Frontend
Vårt fokus är att börja sätta upp HTML och CSS för vårt projekt utifrån uppgiftskraven.

En användarvänlig hemsida krävs för att medlemmarna i Älvsbyns kommun enkelt ska kunna hitta lokala evenemang.

Detta bekräftas när vi testar formulär med testdata och testar storlek på sidan (datorskärm och mobilskärm).

1 vecka

## Sprint goal 2: Databasmodellering
Vårt fokus är att börja programmera databasen och skriva verksamhetsdriva frågor.

Vi tror att det krävs för att lagra data säkert.

Detta bekräftas när har vi använder testdata och kan se att vi kan lagra data på ett säkert sätt.

## Sprint goal 1: Planering

Vårt fokus är att planera projektet med tydliga user stories och strukturen på databasen.

Vi tror att det kommer underlätta vårt arbete som utvecklare.

Detta bekräftas när vi börjar programmera.
